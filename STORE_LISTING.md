# Материалы для публикации в Chrome Web Store

Всё, что нужно вставить в [Developer Dashboard](https://chrome.google.com/webstore/devconsole).
Скопировано отсюда в дашборд — вручную, автоматической загрузки метаданных нет.

## 1. Package

Загружаемый файл: `dist/work-zilla-notifyer-1.0.0.zip` (собирается `./build.sh`).
`manifest.json` лежит **в корне** архива, иконки — в `icons/`.

## 2. Store listing

  ```

  ```
- **Short description** (≤132 символов):
  ```
  Скачивает .ics-напоминание проверить публикацию по заданию Work-Zilla: дата, текст задания и ссылка в вашем календаре.
  ```
- **Category**: Productivity
- **Language**: Russian
- **Detailed description** (≤16000 символов):

```
Расширение помогает не забыть проверить публикацию по уже сданному заказу на Work-Zilla.

Как это работает
1. Откройте раздел «В работе» на client.work-zilla.com — у каждого задания с установленным напоминанием появится значок 🔔. Наведите на него, чтобы увидеть дату и ссылку.
2. Откройте чат нужного задания — внизу справа появится панель.
3. Укажите дату и время проверки. При необходимости вставьте ссылку на публикацию, которую нужно проверить (Авито, отзыв, статья, карточка товара).
4. Нажмите «Сохранить и скачать .ics» — скачается файл события календаря, а напоминание сохранится в браузере.

Что попадает в событие календаря
— Название задания
— Имя заказчика и сумма заказа
— Текст последнего сообщения по заданию
— Ссылка на публикацию (или на чат задания, если ссылка не указана)

Откройте скачанный .ics-файл — событие добавится в Google Calendar, Outlook, Apple Calendar или любой другой календарь, которым вы пользуетесь. Дальше напоминание работает уже средствами вашего календаря.

Важно
Расширение не отправляет push-уведомления само. Оно формирует файл события календаря и сохраняет отметку в браузере; уведомление в назначенный момент показывает ваш календарь.

Приватность
Расширение работает только на страницах client.work-zilla.com, только в вашем браузере. У него нет собственного сервера, нет аналитики и нет рекламы: данные заданий и отметки о напоминаниях хранятся локально, в localStorage, и никуда не передаются. Разрешения Chrome API не запрашиваются.

Расширение не связано с Work-Zilla и не является её официальным продуктом.
```

## 3. Privacy

**Privacy policy URL** — обязателен. Текст лежит в `PRIVACY.md`; его нужно
опубликовать по постоянному публичному URL и вставить ссылку сюда.
Причина обязательности: расширение читает содержимое посещаемой страницы и
хранит его локально, а Chrome Web Store требует раскрывать обработку данных
**даже когда данные не покидают устройство**
([User Data FAQ, п. 3](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)).

Ответы на вкладке **Privacy** (Data usage):

- **What user data do you collect?** — отметьте:
  - `Website content` — да (читается разметка страницы work-zilla: заголовок, заказчик, сумма, последнее сообщение, ссылки).
  - `Personally identifiable information` — нет (имя заказчика хранится как часть текста задания, но разработчику не передаётся; если ревьюер попросит — можно отметить и объяснить локальность).
  - Остальные категории (health, financial, authentication, personal communications, location, web history, user activity) — **нет**.
- **How is the data used / purposes** — App functionality. Только для работы единственной функции расширения.
- **Is the data sold to third parties?** — No.
- **Is the data used or transferred for purposes unrelated to the item's single purpose?** — No.
- **Is the data used or transferred to determine creditworthiness or for lending purposes?** — No.
- **Certify: I do not sell or transfer user data to third parties...** — отметить.

Три обязательные сертификации внизу формы — все три отметить.

### Justification for permissions

Вкладка с обоснованием доступа (текст для поля):

```
Расширению нужен доступ только к https://client.work-zilla.com/*.

Обоснование: расширение добавляет интерфейс напоминаний в уже открытую и
авторизованную пользователем страницу Work-Zilla. Без доступа к этому домену
невозможно выполнить единственную заявленную функцию:

1) прочитать из раздела «В работе» данные задания (название, заказчик, сумма,
   последнее сообщение, ссылка), чтобы подставить их в событие календаря;
2) добавить на страницу чата задания панель выбора даты и времени проверки и
   кнопку скачивания .ics-файла;
3) показать значок 🔔 у заданий, для которых напоминание уже установлено.

Расширение не запрашивает API-разрешения Chrome (в manifest нет блока
permissions), не обращается к другим сайтам, не содержит сетевого кода и не
передаёт прочитанные данные куда-либо: они остаются в localStorage браузера
пользователя.
```

### Remote code

- **Does your extension use remote code?** — **No**. В пакете только
  `content.js`; удалённо ничего не загружается и не исполняется.

### Single purpose

```
Расширение создаёт напоминания о проверке публикации по заданиям Work-Zilla:
сохраняет выбранную дату и формирует .ics-файл события календаря.
```

  Скриншоты нужно снять самостоятельно — в этой среде браузера нет, а вход в
  аккаунт Work-Zilla всё равно за вами. Что снять:

  2. Панель выбора даты и ссылки в чате задания;
  3. Открытый .ics-файл или событие в календаре.
  На первом скриншоте держите в кадре панель расширения — по ней ревьюер
  быстрее поймёт функцию.

- **Marquee promo tile** — 1400×560 (опционально).

## 6. Риски, о которых стоит знать заранее

- **Товарный знак в названии.** «Work-Zilla» — чужая торговая марка, и в
  названии расширения она стоит первой. Раздел политики «Impersonation &
  Intellectual Property» запрещает выдавать себя за другое лицо или продукт;
  само по себе упоминание совместимости обычно проходит, но жалоба
  правообладателя приведёт к снятию расширения. Нейтральная замена без
  потери смысла: `Напоминание о проверке публикации (для Work-Zilla)`.
  Решение оставляю за вами — сейчас названия я не менял.
- **Ожидания от «напоминания».** Расширение не показывает уведомлений само:
  оно отдаёт .ics-файл, а напоминает календарь. В текстах листинга это
  сказано прямо, чтобы ревью не увидело вводящее в заблуждение описание.
- **Хрупкость к вёрстке.** Функция держится на CSS-классах чужого сайта. Если
  Work-Zilla поменяет разметку, интерфейс перестанет появляться — это
  описано в README и стоит упомянуть в ответах на отзывы.
- **`build/ibsrv/publication.yaml`** — файл от проекта 1С с локальным путём
  `d:\soft\...`. К расширению отношения не имеет; в архив не попадает
  (сборка идёт по белому списку). Рекомендую удалить из репозитория.
