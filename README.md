# Work-Zilla Notifier (расширение браузера)

- В списке заданий, в разделе **"В работе"**, у задания появляется 🔔, если для
  него уже установлено напоминание (наведите — покажет дату/время).
- На странице чата конкретного задания (`/freelancer/<id>`) внизу справа
  появляется плавающая панель: выбираете дату/время проверки и жмёте
  "Сохранить и скачать .ics" — напоминание сохраняется (колокольчик в списке
  загорится) и скачивается `.ics`-файл с названием, текстом задания и ссылкой
  на чат для импорта в любой календарь (Google Calendar, Outlook, Apple Calendar).

Работает целиком в браузере поверх уже открытой (авторизованной) страницы —
никаких токенов, паролей или серверов не требуется. Данные заданий и отметки
о напоминаниях хранятся локально в `localStorage` браузера.

## Установка (Chrome / Edge)

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите **Режим разработчика** (переключатель справа вверху).
3. Нажмите **Загрузить распакованное расширение** и укажите папку `work-zilla-notifyer`.
4. Откройте `https://client.work-zilla.com/freelancer/current-orders` — в разделе
   "В работе" у заданий с установленным напоминанием появится значок 🔔.

## Как пользоваться

1. Откройте чат нужного задания (клик по заданию в списке "В работе").
2. В плавающей панели внизу справа укажите дату и время проверки, при желании —
   ссылку на внешний ресурс, где нужно проверить публикацию (Авито, отзыв и т.д.),
   и нажмите "Сохранить и скачать .ics".
3. Откройте скачанный файл (или импортируйте вручную) — событие добавится в календарь.
   Если ссылка на публикацию указана, событие ведёт на неё (иначе — на чат задания);
   в описании события сохраняются обе ссылки.
4. Вернувшись к списку заданий, у этого задания появится 🔔 — значит, напоминание
   для него уже стоит (наведите курсор, чтобы увидеть дату и ссылку).

## Публикация в Chrome Web Store

- `./build.sh` — прогоняет проверки (лимиты полей манифеста, размеры иконок,
  синтаксис `content.js`, содержимое архива) и собирает
  `dist/work-zilla-notifyer-<версия>.zip` с манифестом в корне. Сборка идёт по
  белому списку, поэтому `build/`, `README.md` и прочее в пакет не попадают.
- `STORE_LISTING.md` — готовые тексты для листинга, обоснование доступа и
  ответы на вкладке Privacy в Developer Dashboard.
- `PRIVACY.md` — политика конфиденциальности; её нужно опубликовать по
  публичному URL и указать в дашборде.
- `tools/make_icons.py` — пересобирает иконки 16/32/48/128 в `icons/`
  (чистый Python, без зависимостей). Замените их, если появится свой брендинг.

Порядок действий: заполнить `PRIVACY.md` и опубликовать его → запустить
`./build.sh` → загрузить zip в Developer Dashboard → заполнить Store listing и
Privacy по `STORE_LISTING.md` → добавить скриншоты 1280×800 → отправить на ревью.

## Если разметка сайта изменится

Расширение находит раздел по заголовку "В работе" и разбирает карточки заданий
по CSS-классам (`order-container`, `text-wrapper`, `partner-name`, `param-title`,
`message-text` и т.д.) в `content.js`. Если work-zilla.com изменит вёрстку и кнопки
перестанут появляться — нужно поправить селекторы в функциях `extractTask` и
`processAll` под новую разметку.
